📌 학과 소개

통계학, 컴퓨터공학, 데이터 사이언스를 기반으로 방대한 데이터를 수집·분석·시각화하는 기술을 학습하고, 데이터 기반 의사결정과 전략 수립에 기여할 수 있는 빅데이터 전문 인재 양성을 목적으로 하는 학과이다.

✅ 이런 학생에게 추천

•수학, 통계, 데이터 처리에 흥미가 있고 데이터를 체계적으로 분석하는 것을 좋아하는 학생
•사회·경제적 현상을 숫자와 데이터로 모델링하고 분석하는 과정에 흥미가 있는 학생
•논리적 사고를 바탕으로 데이터를 해석하고 패턴과 의미를 도출하는 것을 좋아하는 학생
•데이터 기반 의사결정과 문제 해결 과정을 공학적으로 탐구해 보고 싶은 학생
